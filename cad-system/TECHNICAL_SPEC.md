# CAD 图纸版本对比与质量检测系统技术规格

## 1. 总体设计原则

- **专业精度**：差异检测精度满足建筑行业专业标准，支持细粒度变化识别。
- **可追溯性**：对比结果与问题分类可溯源至原图对象、图层与版本。
- **可扩展性**：支持 DWG/DWF/PDF 扩展与新专业规则的快速接入。
- **高可用性**：支持批量处理与任务队列，适配大规模图纸集。

## 2. 功能模块与职责

### 2.1 文件解析与规范化

- **DWG/DWF/PDF 解析**：
  - DWG：对象级解析（几何、块、文字、标注、图层属性）。
  - DWF/PDF：矢量与图元解析（若为扫描件则启用 OCR 与几何抽取）。
- **规范化模型**：统一为中间表示（Geometry IR），含几何对象、属性、图层、块、标注。
- **坐标与尺度对齐**：基准点/坐标系/缩放归一，保障跨版本可比性。

### 2.2 智能差异引擎

- **对象匹配**：
  - 几何匹配（拓扑+空间索引+哈希特征）。
  - 文字/标注匹配（字符串相似度+锚点位置）。
  - 图层属性匹配（颜色/线型/可见性/冻结/锁定）。
- **差异类型**：
  - 新增、删除、修改、移动、属性变化、标注变化、图层变化。
- **多版本对比**：支持 2-N 个版本差异对比，形成版本差异链路。

### 2.3 质量检测与异常分类

- **规则引擎**：基于建筑设计规范与企业标准构建规则库。
- **异常类型示例**：
  - 结构冲突、构件重复、标注错误、图层违规、线型不一致、尺寸异常。
- **严重性评级**：按风险等级分级（高/中/低），并形成修订建议。

### 2.4 可视化与交互

- **差异高亮**：按图层/对象类型/专业进行差异高亮显示。
- **问题列表联动**：点击问题跳转定位到原图对象。
- **图纸叠加模式**：支持前后版本叠加、差异遮罩与透明度调整。

### 2.5 报告与输出

- **对比报告**：
  - 修改统计、问题分类、风险评级、建议措施、差异清单。
- **质量评估报告**：
  - 依据建筑设计规范输出评估与整改建议。
- **差异截图**：
  - 对所有差异自动生成原图截图，支持导览跳转。

### 2.6 版本管理

- **版本库**：图纸版本存档与元数据管理。
- **变更记录**：以对象级变化为主线记录变更日志。
- **回溯与审计**：支持版本回溯、批次回溯与审计记录。

### 2.7 批量处理与任务编排

- **任务队列**：支持批量图纸集的自动化对比与报告生成。
- **断点续作**：大规模批量任务可重试与续作。

## 3. 数据模型（核心表/实体）

- **Drawing**：id、name、format、discipline、project_id、created_at
- **DrawingVersion**：id、drawing_id、version_no、file_hash、created_at
- **GeometryObject**：id、version_id、type、layer_id、geometry_hash、bbox
- **Layer**：id、version_id、name、color、linetype、visibility
- **DiffRecord**：id、base_version_id、target_version_id、object_id、diff_type、severity
- **Issue**：id、diff_id、category、severity、description、suggestion
- **Report**：id、version_pair_id、type、path、created_at

## 4. 对比算法与精度保障

- **空间索引**：R-tree/Quadtree 进行快速空间匹配。
- **几何哈希**：对线段、曲线、多段线、块等对象进行特征哈希。
- **容差机制**：依据行业标准设置容差阈值与对齐策略。
- **精度校验**：对细微变化（如标注文字、层属性）进行高精度比对。

## 5. 差异截图与原图导览

- **截图策略**：
  - 基于差异对象 bounding box 自动裁剪。
  - 支持多尺度截图（局部 + 原图定位缩略图）。
- **导览**：
  - 差异列表与原图视图联动，支持一键定位。

## 6. 批量处理流程（示意）

1. 图纸集导入与版本归档。
2. 批量对比任务入队（按专业/图纸集/楼栋）。
3. 执行对比与质量检测。
4. 差异截图生成与报告输出。
5. 结果审阅与问题闭环处理。

## 7. 部署与安全

- **部署模式**：支持单机/私有云/本地局域网。
- **权限控制**：项目/专业/角色级权限管理。
- **审计日志**：对关键操作保留审计记录。
- **数据安全**：版本文件与报告可加密存储。

## 8. 非功能性指标

- **性能**：单张图纸对比秒级响应，批量任务可并行处理。
- **稳定性**：支持长时间批量任务运行。
- **可维护性**：模块化解耦，规则库可配置化更新。

## 9. API 与集成（建议）

- **对比任务 API**：提交任务、查询任务、获取报告。
- **报告 API**：按项目/图纸/版本检索差异报告。
- **版本 API**：版本上传、归档、回溯、审批。

## 10. 实施里程碑（建议）

- **M1：基础对比能力**（DWG 两版本对比 + 差异可视化）
- **M2：质量检测与报告**（规则引擎 + 报告模板）
- **M3：批量处理与版本管理**（任务编排 + 版本库）
- **M4：多格式与智能增强**（DWF/PDF + 智能标注优化）
